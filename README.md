# Курак: сайт агентства

Next.js 16 (App Router) + TypeScript + CSS Modules + Zustand. Главная и страница команды по документу «Сайт Курак — концепция».

## Идея

Курак по-кыргызски значит лоскутное шитьё. Каждое из восьми направлений агентства — свой «лоскут»: свой цвет и узор, одинаковые по всему сайту (меню, кейсы, руководители, подборка). Посетитель отмечает услуги, и в шапке из них сшивается его собственный курак. Подборка сохраняется на устройстве и подставляется в заявку.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3210
npm run build && npm start
```

## Два варианта лендинга

Переключатель «Вариант 1 / 2» стоит в шапке и подвале обоих вариантов.

| | Вариант 1 «Меню-курак» | Вариант 2 «Полотно» |
| --- | --- | --- |
| Адрес | `/` (+ `/komanda`) | `/v2` |
| Идея | меню услуг, из которого собираешь свой курак | история на скролле: курак сшивается на глазах |
| Тема | светлая | ночная (те же токены, блок `:root:has(.v2-theme)` в `tokens.css`) |
| Движение | спокойное, одна проявка | Lenis + GSAP ScrollTrigger: закреплённая сборка лоскутов, горизонтальная лента услуг, загорающийся манифест, стопка кейсов, бегущая строка, кольцо лоскутов, подвал-шторка, магнитные кнопки, курсор-спутник |

Вариант 2 устроен так, чтобы анимации не тормозили загрузку: секции серверные, анимации подключаются «островками» `<Scene>` из `src/lib/scenes.ts`, когда браузер освободится. При «уменьшить движение» плавный скролл и сцены не включаются, страница остаётся обычной вёрсткой. Подборка услуг и черновик заявки общие для обоих вариантов.

## Демо на GitHub Pages

https://seitek2002.github.io/kurak-site/

```bash
npm run deploy:pages              # собрать статикой и запушить в ветку gh-pages
node scripts/deploy-pages.mjs --no-push   # только собрать в out/
```

Скрипт собирает сайт с `GITHUB_PAGES=true` (статический экспорт, `basePath: /kurak-site`), кладёт `.nojekyll` и форс-пушит `out/` в `gh-pages`. Pages раздаёт ветку `gh-pages`, папка `/`.

На Pages нет сервера: обработчик заявки `src/app/api/lead/route.api.ts` в статическую сборку не входит, и форма пишет, что это демо и заявка не отправлена. Для боевого сайта нужен хостинг с сервером (Vercel или свой Node) либо внешний приёмник заявок в `NEXT_PUBLIC_LEAD_ENDPOINT`.

## Настройки

Скопируйте `.env.example` в `.env.local` и заполните:

- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` — заявки уходят в Telegram-бота. Без них форма честно отвечает «не подключена» (503) и не делает вид, что заявка ушла.
- `NEXT_PUBLIC_META_PIXEL_ID`, `NEXT_PUBLIC_GA_ID` — пиксели ретаргетинга (по концепции ставим с первого дня). Пусто — скрипты не грузятся. Событие `Lead` / `generate_lead` отправляется после успешной заявки.
- `NEXT_PUBLIC_SITE_URL` — боевой адрес для sitemap, canonical и Open Graph.

## Образцы вместо фактов

Всё, что агентство ещё не прислало, хранится в `src/content/site.ts` как `Draft` и на сайте обведено пунктирным «стежком». Вписали настоящее значение и поставили `draft: false` — пунктир исчезает. Ни одна цифра, кейс или отзыв на сайте сейчас не настоящие.

- [ ] Анимированная 2D-сцена команды для `/komanda` (сейчас портреты стоят группой)
- [ ] История агентства и примеры к ценностям
- [ ] Телефон, Telegram, Instagram, адрес офиса (в `SITE.contacts`, ссылки в `*Href`)

- [ ] Решение по языкам. Важно: в Dela Gothic One нет кыргызских ң ү ө, для кыргызской версии заголовков понадобится другой шрифт
